# SmartStock EOQ — Demo interfaccia

Questa cartella contiene una demo statica e navigabile dell'interfaccia del progetto SmartStock EOQ.

## Pagine

- `index.html`: dashboard
- `inserimento.html`: form dimostrativo
- `risultati.html`: confronto EOQ, Safety Stock e Reorder Point
- `css/style.css`: stile grafico originale del progetto

## Nota

La demo non esegue il backend Java/Spring Boot e non utilizza PostgreSQL. Il codice completo è distribuito separatamente nell'archivio del progetto.
